An Outcome-Based Education (OBE) question paper for the **Software Design** course, built on Bloom's Taxonomy (Knowledge and Understanding levels) and aligned with the BNQF standard.

---

## Exam Details

| Item | Detail |
|---|---|
| **Course** | Software Design |
| **Total Marks** | 40 |
| **Time** | 1 hour |
| **Questions given** | 8 (each 8 marks) |
| **Questions to answer** | Any **5** (5 × 8 = 40) |
| **Bloom levels** | C1 Knowledge, C2 Understanding |

## Course Outcomes (CO)

| CO | Description |
|---|---|
| **CO1** | Explain the fundamentals of software design: the design process, modularity, coupling, cohesion, abstraction and encapsulation |
| **CO2** | Describe architectural styles and enterprise architecture patterns (layered, MVC, ORM, etc.) |
| **CO3** | Describe GoF design patterns, their intent and their classification |
| **CO4** | Explain design quality metrics and user interface design principles |

---

## Instructions

- Answer any **five** of the following eight questions.
- Each question carries **8 marks**.
- Write clear and short answers. Examples are welcome.

---

## Questions

### Q1. [8 marks] `C1 + C2` `CO1`
What is software design? Explain its basic steps and its outcome.

### Q2. [8 marks] `C1 + C2` `CO1`
What makes a good software design? Explain modularity, coupling, cohesion, abstraction and encapsulation.

### Q3. [8 marks] `C1 + C2` `CO2`
What is software architecture? Briefly explain any five architectural styles.

### Q4. [8 marks] `C1 + C2` `CO2`
Explain the MVC pattern and Object-Relational Mapping (ORM).

### Q5. [8 marks] `C1 + C2` `CO3`
What are design patterns? Explain the classification of GoF patterns.

### Q6. [8 marks] `C1 + C2` `CO3`
Explain the Singleton and Observer patterns.

### Q7. [8 marks] `C1 + C2` `CO4`
Explain the Chidamber & Kemerer (CK) metrics: CBO, LCOM, WMC, DIT and NOC.

### Q8. [8 marks] `C1 + C2` `CO4`
Explain the fundamental UI design principles and the guidelines for presenting information.
